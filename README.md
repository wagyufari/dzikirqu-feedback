<p align="center">
  <strong>Report bugs, request features, and share ideas for DzikirQu, the ad-free, privacy-first Islamic companion for iOS.</strong>
</p>

---

This repository holds no source code. It is the public place where feedback for DzikirQu is collected and tracked, using GitHub Issues.

## How to give feedback

1. Open the [Issues tab](https://github.com/wagyufari/dzikirqu-feedback/issues).
2. Search first. Someone may have already reported it, and you can add a 👍 or a comment instead of opening a duplicate.
3. Click **New issue** and describe what you have in mind.

## What to post

| Type | Examples |
| --- | --- |
| 🐛 **Bug** | Something crashes, looks wrong, or doesn't behave as expected |
| ✨ **Feature request** | A feature you'd like to see, or an improvement to an existing one |
| 📖 **Content issue** | A typo, a wrong translation, or a data error in the Qur'an, hadith, dzikir, or prayer times |
| 💬 **General feedback** | Questions, thoughts, or ideas about the app |

## Writing a good bug report

Please include as much of this as you can:

- **What happened**, and what you expected to happen
- **Steps to reproduce** it
- **App version**: shown at the bottom of the Explore tab (e.g. `v1.2.3 (45)`)
- **iOS version** and **device model**
- **Screenshots or a screen recording**, if they help

## Guidelines

- One topic per issue, so it can be tracked and closed on its own.
- Be respectful and constructive.
- Don't post personal information (email addresses, location, account details) in a public issue.
- Written in English or Bahasa Indonesia is fine.
